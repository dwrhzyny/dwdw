# תזכורת מים - Android

אפליקציה שמזכירה לך לשתות מים לאורך היום, ומיועדת להיות **קשה להתעלמות**:

- כשמגיע הזמן, נפתח **מסך מלא בסגנון אזעקה** (בדיוק כמו שעון מעורר) - גם אם
  המסך נעול או כבוי, המסך נדלק אוטומטית ומציג "זמן לשתות מים".
- הצליל והרטט **חוזרים על עצמם שוב ושוב** (לא מצפצפים פעם אחת ונעלמים) עד
  שתלחצו על אחד הכפתורים במסך.
- אי אפשר להחליק את ההתראה הצידה כדי להיפטר ממנה - חייבים ללחוץ "שתיתי כוס
  מים" או "הזכר לי שוב בעוד כמה דקות".

## הדרך הכי קלה: לבנות APK בענן עם GitHub Actions (בלי להתקין כלום)

1. פתחו חשבון חינמי ב-https://github.com (אם אין לכם).
2. לחצו **New repository**, תנו שם (למשל `water-reminder`), Public או
   Private, ולחצו **Create repository**. אל תסמנו "Add a README".
3. בעמוד הריפו החדש, לחצו על הקישור **uploading an existing file**. גררו
   לתוכו את **כל התוכן** של התיקייה שחילצתם מה-zip (כולל התיקיות `app`,
   `gradle`, `.github`), ולחצו **Commit changes**.
4. עברו ללשונית **Actions**. אמור לרוץ אוטומטית workflow בשם "Build APK"
   (אם לא - לחצו עליו ואז **Run workflow**).
5. חכו כ-5-10 דקות עד סימן \u2713 ירוק.
6. לחצו על ההרצה שהסתיימה, גללו למטה לאזור **Artifacts**, והורידו את הקובץ.
   חלצו אותו כדי לקבל את ה-APK.
7. העבירו את קובץ ה-APK לטלפון והתקינו אותו (אשרו "התקנה ממקורות לא ידועים"
   אם מבקשים).

## או: לפתוח ולהריץ עם Android Studio

1. התקינו Android Studio: https://developer.android.com/studio
2. **File -> Open** ובחרו את התיקייה שחילצתם מה-zip.
3. חכו ל-Gradle Sync (דורש אינטרנט על המחשב שלכם).
4. **Run** \u25b6 על הטלפון (מחובר בכבל, עם ניפוי שגיאות USB) או אמולטור.

## הגדרה ראשונית באפליקציה

1. פתחו את האפליקציה. תראו מסך הגדרות פשוט:
   - **תזכורות פעילות** - מתג הפעלה/כיבוי.
   - **כל כמה דקות להזכיר** - למשל 60 (כל שעה).
   - **דחייה בדקות** - כמה זמן לחכות אם לוחצים "הזכר לי שוב".
   - **שעות פעילות** - למשל 8 עד 22, כדי שלא תקבלו תזכורות באמצע הלילה.
2. לחצו **שמור**.
3. לחצו **אשר הרשאת אזעקות מדויקות** - זה יפתח את הגדרות האנדרואיד; אשרו
   שם. בלי זה התזכורות עדיין יעבדו, אבל פחות מדויקות בזמן (אנדרואיד עלול
   לדחות אותן בכמה דקות כדי לחסוך בסוללה).
4. אפשר ללחוץ **בדוק התראה עכשיו** כדי לראות מיד איך זה נראה.

## הערות חשובות

- **אופטימיזציית סוללה**: בטלפונים מסוימים (שיאומי, וואווי, סמסונג, וכו')
  המערכת נוטה "להרוג" אפליקציות ברקע כדי לחסוך בסוללה, מה שעלול לעצור את
  התזכורות. אם תבחינו שהתזכורות מפסיקות להגיע - חפשו בהגדרות המכשיר
  "הוצא את תזכורת מים מאופטימיזציית סוללה" או "הרשה פעילות ברקע".
- זו אפליקציה פשוטה לשימוש אישי, לא כלי רפואי - אין בה מעקב אחר כמות מים
  מומלצת יומית מבוסס משקל/גיל וכו', רק ספירת כוסות פשוטה.

## איך זה עובד מאחורי הקלעים

- `AlarmScheduler.kt` + `AlarmReceiver.kt` - במקום אזעקה "חוזרת" (שלא
  מדויקת באנדרואיד מודרני), כל תזכורת מתזמנת בעצמה את הבאה אחריה ברגע
  שהיא מופעלת, כך שהמרווח נשאר מדויק.
- `NotificationHelper.kt` - בונה את ההתראה עם `Notification.FLAG_INSISTENT`
  (גורם לצליל/רטט לחזור על עצמם) ועם `fullScreenIntent` (פותח מסך מלא גם
  מעל מסך נעילה) - אלה שני המנגנונים התקניים של אנדרואיד לאזעקות שאי אפשר
  לפספס.
- `WaterReminderActivity.kt` - המסך המלא שנפתח; לחיצה על כפתור היא הדרך
  היחידה לעצור את הצליל/רטט.
- `PrefsHelper.kt` - שומר את ההגדרות ואת ספירת הכוסות היומית.
